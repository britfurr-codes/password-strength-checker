# Password Strength Checker

## Project Overview
A beginner-friendly cybersecurity project built with Python that evaluates password strength based on length and character variety.

## Features
- Checks password length
- Detects uppercase and lowercase letters
- Checks for numbers and special characters
- Classifies passwords as Weak, Moderate, or Strong

## Technologies Used
- Python
- Regular Expressions (re)
- GitHub Codespaces

## How to Run
1. Open the project in a Python environment.
2. Run `python3 password_checker.py`.
3. Enter a sample password when prompted.
4. View the password strength result.

Do not enter real passwords.

## Testing Results
- abc123: Weak
- Hello123!: Moderate
- Sunshine2026!AB: Strong

## What I Learned
This project helped me practice Python functions, conditional statements, regular expressions, and basic password security concepts.

## Limitations
This is an educational password checker. It does not check for compromised or commonly used passwords and should not be used as a complete measure of password security.
